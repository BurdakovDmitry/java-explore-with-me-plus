#Explore With Me (EWM)
Это приложение, позволяет пользователям делиться информацией о событиях и и находить компанию для участия в них.

#Этапы разработки

##Этап 1: Сервис статистики (Stats Service)

Реализована инфраструктура для сбора и анализа данных о посещаемости ресурсов.
1. **Сбор данных:** Создано хранилище для регистрации обращений к эндпоинтам.
2. **Аналитика:** Реализован расчет уникальных просмотров (по IP) и агрегация статистики за произвольный период.
3. **Технологии:** Spring Boot, PostgreSQL, Docker.
4. **Взаимодействие:** Разработан HTTP-клиент для интеграции статистики в основное приложение.

##Этап 2: Основной сервис (Main Service)

Реализована вся бизнес-логика приложения согласно спецификации API.
Публичный API: Поиск событий с динамической фильтрацией (использован QueryDSL).
Приватный API: Управление собственными событиями, участие в чужих мероприятиях, система подтверждения заявок.
Административный API: Модерация контента, управление справочниками категорий и пользователями.
Интеграция: Основной сервис в реальном времени обращается к Сервису статистики для получения данных о просмотрах.
Валидация: Реализована сложная многоуровневая проверка бизнес-правил (проверка временных интервалов, лимитов участия, статусов модерации).

##Этап 3: Дополнительный функционал (Feature: Comments)

Проект расширен системой комментариев для повышения вовлеченности пользователей.
Возможности: Пользователи могут оставлять отзывы к прошедшим событиям.
Модерация: Реализованы статусы комментариев (PENDING, PUBLISHED, REJECTED).
Безопасность: Добавлены проверки владения (редактировать комментарий может только автор).
Оптимизация: Использование FetchType.LAZY и исключение рекурсивных вызовов в сущностях для обеспечения высокой производительности БД.

##Технологический стек

Java 21 / Spring Boot 3 / Maven
PostgreSQL / Spring Data JPA
Lombok
QueryDSL
MapStruct
Docker & Docker Compose

##Запуск проекта

```bash
mvn clean package
docker-compose up
```

# Контроллеры для реализации Comments: 

ADMIN: (Предлагаю AdminCommentController в директории сomment)
"GET/admin/comments" - Поиск комментариев по параметрам
#text - текст для поиска в содержимом комментарии,
#List<Long> User - поиск по списку авторов комментариев,
#List<Long> Event - поиск по списку событий,
#Enum status - поиск по статусу комментария (опубликован или нет),
#LocalDateTime rangeStart - дата и время не раньше которых оставлены комментарии,
#LocalDateTime rangeEnd - дата и время не позже которых оставлены комментарии,
#Integer from - количество комментарий, которые нужно пропустить для формирования текущего набора,
#Integer size - количество комментарий в наборе

"PATCH/admin/comments/{commentsId}" - обновление статуса комментария - опубликован или отклонен

"DELETE/admin/comments/{commentsId}" - удалить любой комментарий

-------------------------------------------------------------------------

PUBLIC: (Предлагаю CommentController в директории сomment)
"GET/comments" - Поиск опубликованных комментариев по параметрам
#text - Поиск по слову(части слова),
#List<Long> Event - поиск по списку событий,
#LocalDateTime rangeStart - дата и время не раньше которых оставлены комментарии,
#LocalDateTime rangeEnd - дата и время не позже которых оставлены комментарии,
#Integer from - количество комментарий, которые нужно пропустить для формирования текущего набора,
#Integer size - количество комментарий в наборе
#String sort - сортировка по дате

"GET/comments/{commentsId}" - поиск опубликованного комментария

"GET/comments/event/{eventId}" - поиск опубликованных комментариев у события

-------------------------------------------------------------------------

PRIVATE: (Предлагаю PrivateCommentController в директории user)
"GET/users/{userId}/comments" - получение всех опубликованных комментариев пользователя

"POST/users/{userId}/events/{eventId}/comments" - добавление комментария пользователем после посещения события

"GET/users/{userId}/comments/{commentsId}" - получение своего комментария

"PATCH/users/{userId}/comments/{commentsId}" - обновление своего комментария

"DELETE/users/{userId}/comments/{commentsId}" - удаление своего комментария
